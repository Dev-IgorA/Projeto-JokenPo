# 🪨 📄 ✂️ Jekipô

O **Jekipô** é uma versão web moderna e interativa do clássico jogo **Pedra, Papel e Tesoura** (Jokenpô). Desenvolvido como um projeto responsivo para praticar e consolidar fundamentos de desenvolvimento web front-end.

## 🚀 Tecnologias Utilizadas

O projeto foi construído do zero utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica do conteúdo e dos elementos do jogo.
* **CSS3:** Estilização moderna, layout responsivo (Mobile First) e animações de transição.
* **JavaScript (ES6):** Lógica do jogo, manipulação do DOM e computação dos resultados (Vitória, Derrota ou Empate).

## ✨ Funcionalidades

* **Modo de Jogo Contra a Máquina:** Escolha a sua jogada e enfrente a inteligência artificial (escolha aleatória).
* **Placar em Tempo Real:** Contador automático de vitórias, derrotas e empates atualizado a cada ronda.
* **Interface Responsiva:** Adaptado para ecrãs de computadores, tablets e smartphones.
* **Efeitos Visuais:** Feedback dinâmico e animações ao selecionar as opções.

## 📦 Como Executar o Projeto

Não é necessário instalar nenhuma dependência ou servidor local para correr o jogo. Siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até à pasta do projeto:**
   ```bash
   cd jekipo
   ```

3. **Abra o ficheiro principal:**
   * Basta dar um duplo clique no ficheiro `index.html` ou abri-lo diretamente no seu navegador de preferência.
